Conecta el panel (solo la primera vez)

Para que este panel pueda guardar tus productos en la web, necesita una "llave" de GitHub. Se crea una vez y se queda guardada en este navegador.

  1. Abre esta página de GitHub (entra con tu cuenta si te lo pide).
  2. Token name: escribe panel pelotaofertas. Expiration: elige No expiration (o 1 año).
  3. Repository access: marca Only select repositories y elige pelotamazon.
  4. Permissions → Repository permissions → Contents: pon Read and write.
  5. Pulsa Generate token, copia el código que empieza por github_pat_ y pégalo aquí abajo.
No se la des a nadie. Solo se guarda en este navegador.

Añadir un producto

En Amazon.es, con tu sesión de afiliado abierta, usa la barra SiteStripe de arriba: pulsa Obtener enlace → Texto y copia el enlace corto, o Texto e imagen y copia todo el código. Pégalo aquí: el panel saca el enlace y la foto solo.

Si la dejas vacía se verá un dibujo de la categoría.
